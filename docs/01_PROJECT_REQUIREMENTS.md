## 赛题要求

### 核心任务
为 **Ryde**（新加坡网约车平台）构建一个 **AI 驱动的争议解决系统**，处理司机和乘客之间的纠纷。

### 具体场景
1. **路线偏离** — 司机绕路导致多收费
2. **未出现收费** — 司机未到达却收取取消费
3. **车费争议** — 价格计算错误
4. **取消退款** — 取消后的退款问题
5. **服务质量** — 司机态度差/不安全驾驶
6. **财物损坏** — 乘客损坏车辆
7. **安全事件** — 骚扰/不当行为

### 系统要求
- 多 Agent 架构（至少 3 个 agent）
- RAG（检索增强生成）用于政策查询
- 支持新加坡官方语言（英语、中文、马来语、泰米尔语）
- 可解释性（每个决策有理由）
- 人机协作（必要时转人工）

## 评分标准

| 维度 | 权重 | 说明 |
|------|------|------|
| **创新性** | 25% | 独特的解决方案，不只是简单的规则引擎 |
| **技术实现** | 25% | 代码质量、架构设计、AI 技术应用 |
| **商业价值** | 20% | 实际可落地，能解决真实问题 |
| **演示效果** | 20% | Demo 清晰度、用户体验 |
| **完整性** | 10% | 文档、测试、部署 |

### 拿高分的关键点

1. **多 Agent 辩论机制** — 不是单 Agent 决策，而是多个 Agent 辩论后达成共识
2. **RAG 精度** — 能准确检索到相关政策条款，不是模糊匹配
3. **可解释性** — 每个决策都有清晰的推理链（Chain of Thought）
4. **多语言支持** — 新加坡是多元文化社会，支持四种官方语言是加分项
5. **实时性** — 响应速度快，用户体验流畅
6. **可视化** — 有清晰的前端展示决策过程
